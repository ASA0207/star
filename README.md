# AnneX 별관 공식 GitHub Pages

AnneX 별관 길드의 공식 안내 사이트입니다.

## 배포
1. 이 폴더의 모든 파일을 GitHub 저장소 루트에 업로드합니다.
2. GitHub 저장소 `Settings → Pages`로 이동합니다.
3. `Deploy from a branch` → `main` → `/(root)` → Save.
4. 잠시 기다리면 GitHub Pages 주소가 생성됩니다.

## 구성
- `index.html` : 메인 페이지
- `assets/style.css` : 전체 디자인/반응형/애니메이션
- `assets/main.js` : 모바일 메뉴 및 스크롤 애니메이션
